### 口径说明

- 受影响 run 的定义: 同一 (题, 注入) 组合下 A 组失败 —— 即注入真实命中判据；
- 指标 3/4/6 只在受影响 run 上统计，避免"注入根本没生效"稀释数字；
- 指标 5 在 mock 管线下无回归事件（n=0 时记 n/a，不冒充实测）；
- 指标 7 的 UAD 在 mock 管线下偏乐观：判据全部被执行验证；真实实验中由模型生成的候选断言才可能出现从未验证的项。

## 已知限制

- mock 模式的"模型"是脚本化解，不代表模型能力，只代表机制差异；
- B 组的简单 harness 只会盲目重试，不代表 dsh 的完整能力；
- chain 类(持久断链)不可自动修复，C 组诚实上报 halt_escalate，计为失败。
