## 接口约定
- `Assertion`（frozen pydantic 模型）：aid / kind(pre|post|invariant) / subject / predicate / validator_name(6 原语之一) / validator_params / level(0-3) / producer / origin(llm|human|learned) / status(unverified|verified|falsified)；`materialize() -> Validator`
- `AssertionCompiler.compile(candidates) -> CompileReport`（accepted/rejected/compile_rate）；候选约束 type 不在 6 原语名内 → 丢弃不抛
- `AssertionLedger`：add/get/depends_on/derives_from/triggered/falsify/verify/upstream/downstream；`falsify()` 对未知 aid 返回 None，**永不 raise**
- `EventType` 追加 6 成员（assertion.verified/falsified/escalated/degraded、repair.applied/rolled_back）——**接口变更（字段枚举）**，向后兼容（只增不改）

## 实现要求
- 断言谓词必须可机械判定：validator_name 白名单校验进模型层（6 原语之外的值在构造时即拒绝）
- 编译器不做自然语言解析——候选是结构化约束，自然语言描述只作审计字段
- falsify/verify 全程不抛异常；账本为纯数据结构，不依赖 EventBus/IO
- 状态迁移：unverified→verified→（falsify 终态）；falsified 后 verify() 返回 False 不回翻

## 必须补充的测试
- 正常：6 原语各一编译成功路径；依赖图构建；证伪记账与幂等
- 空值/边界：空批次 compile_rate、level 越界、validator_name 非法、重复 aid
- 异常：未知 aid falsify、非法谓词参数（low>high / 非法正则 / 空 keys）、frozen 模型不可变

## 冒烟测试要求
纯数据结构无 I/O，冒烟 = 全量单测回归（pytest tests/unit/ -x -q）+ 新增测试全绿。
